# Requirements for coherent control of a single-atom nuclear-spin qudit

**Version 5.2.1 | 20 October 2026**

Public records: code on GitHub (https://github.com/vishwaka-2419/surface-nuclear-qudit-control-v5.2.1) and Zenodo (https://doi.org/10.5281/zenodo.23506580, MIT license); numerical results on Zenodo (https://doi.org/10.5281/zenodo.23506670, CC BY 4.0).

## Two distributions of this tree

| Public code release (GitHub / Zenodo software record) |
|---|---|---|
| Code, tests, configs, generated tables and macros | yes | yes |
| `results/` (pulse records, validation records, scans) and `results/pulses/*.npz` | yes | **no** — download the Zenodo dataset (`results.zip`) with `python scripts/fetch_results.py` |
| `figure_data/` | yes | regenerated by `python scripts/build_figures_tables.py` after the results are in place |

**Reproduction from the public release** (workflow):

```bash
git clone https://github.com/vishwaka-2419/surface-nuclear-qudit-control-v5.2.1 && cd surface-nuclear-qudit-control-v5.2.1
python -m venv .venv && source .venv/bin/activate
python -m pip install -r requirements-tested.txt && python -m pip install -e .
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
python scripts/check_release.py --code-only        # code files and license present
python scripts/fetch_results.py                    # downloads results.zip from Zenodo 10.5281/zenodo.23506670 into results/
                                                   #   (or: python scripts/fetch_results.py --zip /path/to/results.zip)
python scripts/check_release.py --content-only     # 39 pulse records, finite coefficients, JSON readable
python -m pytest -q                                # 62 tests
python scripts/verify_pulse.py nominal_N_B1.6_dual # independent propagation of an archived pulse
python scripts/comb_spectrum.py && python scripts/build_figures_tables.py   # figures, tables, macros
```

The loaders read `results/<name>.json` and `results/pulses/<name>.npz`; `fetch_results.py` places the dataset there whatever the folder layout of the archive, and copies coefficients from a top-level `pulses/` directory (present in release v5.2.1) into `results/pulses/` if the dataset does not contain them. The frozen manifest check (`python scripts/check_release.py` without options) applies to the author package only.

This package contains the manuscript, Supplementary Information, calculation code, archived pulse coefficients, numerical results, figures and author working files for a computational study of coherent control of the `I = 7/2` nucleus of a single 49Ti atom on MgO/Ag(100) addressed by ESR-STM. The study uses the full 16-level electron–nuclear Hamiltonian with published parameters. All results are model calculations, not measurements of an operating device.
## Installation

Python 3.11 or later (executed with Python 3.13; library versions in `requirements-tested.txt` and `provenance/environment.json`).

```bash
python -m venv .venv && source .venv/bin/activate
python -m pip install -r requirements-tested.txt
python -m pip install -e .
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
python -m pytest -q
python scripts/check_release.py            # frozen author package: content checks + SHA-256 manifest
```

A LaTeX installation with REVTeX 4.2 (TeX Live `texlive-publishers`), BibTeX and standard packages rebuilds the PDFs: `bash scripts/build_pdfs.sh` (full and anonymised main text and Supplementary Information, cover letter, referee record); `python scripts/make_submission.py` then writes `submission/upload/`.

## Regenerate figures, tables and numbers from archived data

```bash
python scripts/comb_spectrum.py          # transition combs for Fig. 1 (pure algebra, seconds)
python scripts/build_figures_tables.py   # all figures, figure_data/, supplement tables, numbers.tex
bash scripts/build_pdfs.sh
```

`build_figures_tables.py` computes no physics: every curve and number is read from `results/`. Main-text figures are `figures/fig1_overview` … `fig5_electron_state`; supplement figures keep descriptive names. `provenance/figure_manifest.csv` lists the source file of each figure.

## Verify an archived pulse without re-optimizing

```bash
python scripts/verify_pulse.py nominal_N_B1.6_dual
python scripts/verify_pulse.py composable_N_B1.6_dual --start-time-us 769.615835   # any start time (continuously running carriers)
python scripts/verify_pulse.py tracked_electron_B1.6_single --full-step-us 0.000025
```

This propagates the archived real waveform in the projected branches and in the full 16-level space and compares with the archived validation. Fidelity differences and step convergence, not byte-identical JSON, are the comparison.

## Fresh numerical reproduction

Work in a copy; move `results/` aside first. Sequential order:

```bash
mv results results_archived && mkdir -p results/pulses
python scripts/analytical_study.py
python scripts/source_uncertainty_scan.py
python scripts/run_control_study.py --group nominal --workers 2
python scripts/run_control_study.py --group robust --workers 2
python scripts/refine_robust.py
python scripts/validate_new_controls.py
python scripts/operator_convergence.py
python scripts/evaluate_robust.py
python scripts/open_system_study.py
python scripts/virtual_shift_study.py
python scripts/stark_aware_study.py          # second-order design, untracked (reference)
python scripts/stark_tracking_study.py       # second-order design with carrier tracking (Results, drive-induced comb shift)
python scripts/tracked_robustness.py         # calibration tolerance of the tracked pulses (Results, calibration tolerance)
python scripts/start_time_study.py           # 10-us start-time scans and sequence tests of archived pulses (Results, composable gates)
python scripts/composable_study.py --tmax 10 --ntrain 8 --ntest 24 --prefix window   # window-trained pulses (SI Note 9)
python scripts/composable_study.py           # composable designs trained over 0-100 ms and their validation (Results, composable gates)
python scripts/refresh_full_sequences.py     # recompute archived L4 sequence entries with complete-propagator composition
python scripts/wide_scan.py                  # wide-range start-time scans of the nominal and window-trained pulses (SI Note 9)
python scripts/residual_order_check.py       # amplitude scaling of the beyond-second-order residual (SI Note 8)
python scripts/diagonal_frame_study.py
python scripts/dimension_study.py
python scripts/comb_spectrum.py
python scripts/build_figures_tables.py
bash scripts/build_pdfs.sh
python -m pytest -q && python scripts/check_release.py --content-only
```

Fresh optimization takes hours on one CPU core (the 14-tone tracked designs are the slowest, ~25 min each). Iteration limits, seeds, objective histories, mesh settings and stopping messages are archived with every pulse; runs that stopped at their iteration budget are candidate controls, not certified optima.

## Export a waveform

```bash
python scripts/export_waveform.py tracked_electron_B1.6_single --output exports/nuclear_gate.csv
```

The CSV holds time (µs) and the real Hamiltonian coefficient (MHz) multiplying the dimensionless drive operator; the JSON sidecar records carriers (including tracking offsets), operator normalization and frame convention. These are **not calibrated instrument voltages**.

## Directory map

| Directory | Content |
|---|---|
| `src/qudit_control/` | Static model, bounded spline controls, second-order (virtual-electron) model, independent propagators, telegraph and dephasing channels, analytic requirements |
| `scripts/` | Numerical studies, figure/table generation, pulse verification, waveform export, PDF build, release check |
| `results/` | All result JSON/CSV and `pulses/*.npz` coefficients (nominal, robust, stark, tracked, selective, synthetic, window, composable; start-time scans and wide scans) |
| `figure_data/` | Values plotted in each figure |
| `tests/` | Algebra, signs, frames (including carrier-defined frames), gradients, channel bounds, numerical methods |
| `provenance/` | Input hashes, execution logs, tested environment, figure manifest, release checks |
